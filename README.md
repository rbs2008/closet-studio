# Closet Studio

[Open Closet Studio](https://rbs2008.github.io/closet-studio/) · [View the GitHub repository](https://github.com/rbs2008/closet-studio) · [Privacy policy](https://rbs2008.github.io/closet-studio/privacy-policy.html)

Closet Studio is a browser-based wardrobe organizer and outfit planner. Add clothing pieces, keep their details in one place, and build outfit suggestions for different occasions.

## How it works

1. Add a clothing photo. The app compresses it on your device and suggests a color and clothing type. Phones use the compressed photo directly for reliability; desktop browsers may also remove the background.
2. Review or edit the suggested name, type, color, season, and occasions, then save the piece.
3. Generate outfits from your saved wardrobe using occasion, weather, and color preferences. Save favorite combinations for later.

Your wardrobe is stored in the browser on your device; it is not synced to an online account. Photo processing happens on-device. Some image formats and first-use features may require downloading a converter or model.
